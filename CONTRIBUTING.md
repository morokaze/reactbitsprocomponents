# Участие в разработке

1. Создайте форк и отдельную ветку для изменения.
2. Установите Node.js 22 и зависимости командой `npm ci`.
3. Запустите демо через `npm run dev`.
4. Перед pull request выполните `npm run typecheck` и `npm run build`.
5. Для визуальных изменений приложите скриншоты и опишите проверку анимации на компьютере и телефоне.

Сохраняйте читаемое форматирование. Не добавляйте комментарии в исходный код, минификацию и заглушки. Пояснения размещайте в Markdown. Собственные функции называйте одной или двумя буквами; имена React-компонентов, хуков и внешних API сохраняйте понятными и совместимыми.

Не включайте зависимости, результаты сборки, секреты, снимки сторонних сайтов и закрытый исходный код в pull request.
