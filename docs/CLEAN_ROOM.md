## Что означает этот термин здесь

Компоненты реализованы самостоятельно по наблюдаемому результату публичных демонстраций. Термин clean-room используется для описания принципа: изучать внешний вид и поведение, затем писать собственную реализацию.

**Формальная clean-room процедура с разделёнными независимыми командами не проводилась.** Наблюдение, реализация и сравнение выполнялись в рамках одной работы. Эта страница фиксирует происхождение и способ разработки; она не является юридической экспертизой или подтверждением отсутствия любых правовых рисков.

## Источники наблюдений

| Компонент | Публичный визуальный референс | Сохранённые особенности нашей версии |
| :--- | :--- | :--- |
| Cloud Atlas | [Демо React Bits](https://pro.reactbits.dev/docs/components/cloud-atlas) | Более выраженный восходящий поток; направленное размытие с восстановлением |
| Glyph Tide | [Демо React Bits](https://pro.reactbits.dev/docs/components/glyph-tide) | Без взаимодействия с курсором; яркость 1.8 |
| Glyph Ember | [Демо React Bits](https://pro.reactbits.dev/docs/components/glyph-ember) | ASCII-пламя и искры; взаимодействие выключено по умолчанию |

Изучались видимое движение, палитра, плотность символов, реакция на ввод, размеры и публичные настройки. Скриншоты для сравнения использовались как наблюдения; изображения оригинальных демо не включены в публикуемую коллекцию.

## Как строилась реализация

1. **Наблюдение.** Просмотр публичного демо в браузере в нескольких состояниях и моментах времени.
2. **Описание результата.** Фиксация формы, направления движения, переходов, цветов и доступных параметров.
3. **Собственный код.** Создание процедурных полей, шейдеров, Canvas-отрисовки и React-компонентов.
4. **Сравнение.** Проверка реализации в браузере, корректировка обнаруженных визуальных отличий.
5. **Техническая проверка.** TypeScript, production-сборка и проверки поведения в рамках выполненных изменений.

Алгоритмы и конкретные кадры нашей реализации могут отличаться от референсов. Техническая проверка сборки не подтверждает визуальную идентичность.

## Что не использовалось

- Закрытый исходный код компонентов React Bits Pro.
- Извлечение реализации из собранных JavaScript-бандлов или source maps.
- Обход платного доступа, авторизации или других ограничений.
- Перепубликация логотипов, текстур или снимков оригинального сайта.

В репозитории используются собственные реализации, стандартные веб-API и явно перечисленные зависимости. Изображение в README компонента Glyph Ember показывает локальное демо; обложка коллекции — отдельная векторная иллюстрация, а не скриншот референса.

## Правила для будущих изменений

- При добавлении референса укажите его публичную страницу и наблюдаемые свойства.
- Описывайте поведение своими словами; не переносите закрытые реализации или их фрагменты.
- Сохраняйте сведения о происхождении сторонних файлов и их лицензиях.
- Отмечайте намеренные отличия и ограничения проверки.
- Не называйте результат официальным компонентом React Bits или точной копией без подтверждения.
